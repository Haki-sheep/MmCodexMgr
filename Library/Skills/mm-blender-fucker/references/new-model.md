# 从零建模

适用于只有概念 参考图或需求而没有可用模型的任务。这里提炼的是“焚诀”制作流程 不是必须机械执行的固定工序 已有合格输入可直接复用。

## 先选择制作工具

从零建模前先提问 让用户选择 **Tripo 本地 Blender 或其他工具**。如果用户在本任务中已经明确选定则直接沿用 不重复问。不能仅因本机装有 Blender 就默认用脚本现场拼模型。

提问示例：这次从零建模想用 Tripo 生成高模 本地 Blender 制作 还是其他工具？

- **Tripo 等专门的图生 3D 工具** 用于从参考图生成候选几何 Blender 承担后续修形 分件 拓扑 UV 烘焙及需要的绑定。生成结果仍须验收 不承诺自动一比一还原。
- **本地 Blender** 直接按参考制作与雕刻 按实际目标决定细分与拓扑方法。通过多视角白模检查完整体积 正面投影贴合不能代替三维形体成立。
- **其他工具** 由用户指定名称或现有文件入口 再核实其实际可用能力。

使用带自由输入的提问工具时 可列 Tripo 和本地 Blender 两个选项 并在问题中说明也可输入其他工具 遵守提问工具本身的选项限制。

选择某个生成工具不等于该服务已经连接。核实当前可用的插件 API 或浏览器能力 以及本次所需账户 额度和运行条件 缺少条件时指出具体阻碍。可继续整理参考等独立工作 不擅自安装另一套大型生成环境 不静默切回本地拼模。用户提供已生成模型时直接转入改模或交付。

## 制作流程

### 风格与一致参考

从用户参考中确认造型 比例 材质和表现方式 已明确的风格不重新设计。需要多视角还原时准备概念四视图 检查同一角色的轮廓 服装结构 配件位置和色块一致性。看不到的结构属于补全 假设应明确 不当作原始事实。

涉及姿态和绑定时准备 A Pose 四视图 或沿用项目要求的 T Pose 等标准姿态。统一正侧背比例 肩 腰 膝 脚底高度及相机投影。概念与姿态参考可合并 已有合格四视图时不重复生成。

需要生成或修改参考图时使用当前可用的图像生成能力 输出与检查参考图 不将参考效果图称作已生成的三维模型。

### 生成或制作高模

按已选路线生成或制作候选高模 专门的生成工具输出网格 本地 Blender 路线直接制作形体。确认实际文件中包含可检查的几何与材质 不以生成器预览图代替模型检查。

先关掉贴图与复杂材质 用中性白模对照正面 侧面 背面和必要斜角 核对头身比例 轮廓 体积 遮挡关系与部件衔接。明显形体偏差先修正或淘汰候选 不用贴图 阴影或固定相机掩盖。

### 分件与低模拓扑

高模形体满足当前阶段目标后 再按衣物 附件 材质边界和变形需求分件 逐部件整理低模拓扑。已有合用的生成拓扑可以保留 不为形式重做所有网格。

低模应保住轮廓 关键转折和变形区域 对照高模检查拓扑与实际平滑结果 清理意外内面 重叠 非流形和破面 不只看面数下降。需要蒙皮时检查关节处边流与可变形空间。

### UV 贴图与烘焙

在低模与贴图阶段持续检查 UV 用棋盘格查看拉伸 接缝 密度和留边 确认重叠是否出于明确设计。法线和其他细节按实际需要从高模烘焙 排查穿射 接缝与投射距离 不把所有贴图一律生成。

**Base Color 只表达固有色 不写入 AO 定向光照 高光或投影。叠加贴图和叠加材质遵守同样的分离原则。** 参考图含光照时 先区分色彩与受光结果 不把整张受光画面直接投影成最终固有色。

需要 AO Normal Roughness Metallic 等信息时分别生成或烘焙对应贴图 光照与阴影由目标材质和渲染环境处理。检查色彩空间 通道约定与实际材质连接。

### 细节修复与交付

回到已确认四视图逐项比较形体和纹理 多视角白模检查与有材质检查分别进行。需要绑定时再完成骨架 权重和必要的姿态采样 不默认增加动画。

要求 Unity 交付时转入 [Unity 导入与覆盖](unity-delivery.md) 用目标管线实际渲染 核对轮廓 色阶 描边及光照响应。

## 阶段检查

参考一致性 高模白模 低模与 UV 最终材质分别检查。用户要求逐阶段验收时 提交当前阶段的真实结果和已知差距 等确认后再做依赖它的工作；否则自主检查并保留必要证据 不把每个工序都变成额外审批。

相似度不够时说明偏差和是否存在明确修正方向 无法改善则报告当前路线不达标 不用后续拓扑 烘焙或 Shader 工序堆叠掩盖失败。
