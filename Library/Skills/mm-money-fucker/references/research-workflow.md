# 每日研究流程

## 0 截图与文字反馈

用户提供截图 持仓文字或执行反馈时先处理本节 只反馈状态不需要重新研究全池 数据结构与命令见 [持久记录契约](report-contract.md#持久记录契约)

1. 先运行 `python -X utf8 scripts/portfolio_state.py current` 读取最近完整快照及之后待核对的更新 按需要读取 `history` 不依赖当前聊天记忆
2. 直接使用可用的图像理解能力读取截图 脚本只存结构化记录 不提供OCR 无法看见图片时明确说明 不从文件名猜持仓
3. 识别产品六位代码及份额类别 持有金额 总份额 可卖份额 成本 收益 可用现金 待确认订单与页面时点 只保存确实展示的字段 缺失用null 持有金额不能当份额 持仓收益不能当账户总收益 总资产不能当可用现金
4. 保存截图中的观察日期和时间 截图没有时点时不得把收到图片的时间当拍摄时间 用户明确说是当前状态时可采用本轮时刻并标为user_reported_current 否则observed_at为null并记录待确认项
5. 区分完整持仓与局部列表 单张截图 页面滚动未到底或被遮挡时默认局部 同批多图对同一基金去重 不把重复展示相加 不把未出现的旧持仓视为已经清仓 非候选池产品也保留
6. 清晰且无矛盾的事实直接保存 无需逐项再确认 模糊数字 未明确份额类别 和新旧同一时点冲突保留原始来源与unresolved 涉及具体交易或会实质改变当前持仓时只询问必要缺项 其余研究可继续
7. 有可用本地原图路径时使用file_path归档 原图含支付密码 验证码或其他无需保留的凭证时只存相关字段和来源引用 无法取得本地附件时如实注明原图未独立归档 不声称聊天附件永久可访问
8. 用append保存记录并读回current 核对代码 日期 金额 单位与保存结果 更正使用supersedes关联被更正记录 不覆盖旧文件 不将用户最新提供的旧截图当成当前快照
9. 简短回复已识别的持仓与现金口径 保存结果和待确认项 不把截图读取成功表述为已登录或核验交易账户 交易截图可记录成交事实 单纯持仓变化不能证明某笔建议已执行

状态由完整快照及后续反馈共同判断 current中的basis_snapshot只是最近完整持仓的依据 后续局部快照 订单 流水 未定时点记录和未解决冲突仍须核对 不可跳过updates_to_review直接把账户标为已同步

完整快照可以明确表示无持仓 但必须有完整范围证据 未显示可用现金不等于余额为0 未显示可卖份额不支持精确赎回 未反馈建议时不推断用户已交易 仅将执行结果记录为未知

## 1 确定研究时点与账户事实

读取用户本轮要求 配置及持久状态 记录北京时间的完整截止时刻 配置中的last_confirmed_state仅为历史起点 有新记录时按证据时点核对 不反复恢复初始1000元现金与空持仓

区分实验总预算 当前已到账现金 已确认持仓 可赎回份额 待确认订单与在途资金 同一用户多次反馈按实际确认顺序对账 仅有买入建议不增加持仓 没有用户反馈不能推断已卖出

初始1000元是用户自报预算 不是读取到的支付宝余额 可按明确标注的用户自报现金做研究 不能写成账户验证通过 若后续有未确认建议或状态不明 继续完成全池研究 在表尾写持仓待同步 精确可执行买卖金额暂不给 无需在无人值守运行中反复提问

检查境内基金交易日与基金自己的开放日 QDII还须核对境外假日 普通周末和法定调休工作日不能简单等同证券交易日 没有取得可靠交易日历时明确写未核实

## 2 更新全池基础资料

每次至少覆盖10只不同基金 默认读取12只初始候选 可用同主题更合适的产品替换 替换要核对代码与份额 类似指数重叠不作为新增分散风险

核查字段

| 字段 | 使用要求 |
| --- | --- |
| 名称 代码 类别 | 代码是保留前导零的六位字符串 A/C/B类不能互换 |
| 投资范围 | 指数基金记录指数与目标ETF 主动基金记录策略和经理 |
| 净值与日涨跌 | 记录净值日期 公告可用时间 来源与获取时间 |
| 历史收益 | 明确区间 比较复权总回报 不将低单位净值称为便宜 |
| 开放状态 | 基金公司开放不代表用户渠道可买 支付宝销售状态单独核实 |
| 申购与赎回 | 最低金额 费率分段 截止时间 确认及到账规则 |
| 持有期限 | 以登记确认规则与批次计算 不按付款日自行猜测 |
| 持仓 | 标记报告期和披露日 联接基金穿透目标ETF |
| 规模与变更 | 清盘合并 风格漂移 经理变更 跟踪偏差 |

对于今天14点的报告 昨日净值通常仍是最近公布值 当日指数涨跌如作为参考必须标明时点 不得写成当日已确认基金净值

优先批量取数 再检查异常数据 避免每只基金无差别搜索相同宏观新闻 某来源失败可使用明确标记的替代来源 记录首错与口径变化 替代来源仍缺失就显示缺失 不伪造成功

## 3 搜集可改变判断的事件

先搜索上次截止时刻后的新增事实 首次运行可回看最近7个自然日 并按需要追溯原始事件 不把7日窗口当成必须忽略更早政策的边界

| 层次 | 搜索内容 | 优先原始来源 |
| --- | --- | --- |
| 宏观 | PMI 通胀 就业 信贷 消费 央行利率 实际利率 汇率 | 统计局 央行 财政部 美联储 |
| 政策 | 正式文件 实施细则 补贴预算 执行时间 贸易限制 | 国务院 监管机构 部委 原文件 |
| 行业 | 订单 库存 产品价格 供需 产能 监管审批 | 行业主管部门 行业协会 公司公告 |
| 企业 | 财报 业绩指引 现金流 合同 审批 处罚 | 交易所披露 公司投资者关系 |
| 市场 | 收盘与日内参考 成交 风格切换 ETF份额 资金风险 | 交易所 指数公司 基金公司 |
| 基金 | 最新公告 分红 份额 经理变化 限购 费率 | 基金公司 产品概要 招募说明书 |

可直接使用的查询形式 用具体日期 产品 公司或指数替换变量 不照抄历史年份

```text
site:stats.gov.cn 当前月份 PMI 发布 解读
site:pbc.gov.cn 最近日期 货币政策 利率
site:csrc.gov.cn 最近日期 政策 实施
site:federalreserve.gov 最近会议日期 statement
基金代码 基金名称 最新招募说明书 赎回费
基金代码 目标ETF 跟踪指数 季度报告
核心成份公司 最近季度报告 订单 业绩预告
行业名称 最近日期 政策 价格 库存 订单
```

先检索再打开与结论相关的原文 仅有标题或摘要的内容标为待核实 不将未经原文核实的重大事件作为精确新增买入的主要理由 遇到403 保留访问限制 可查相同机构的正式公告副本 不用营销文章替代原公告

## 4 形成事件与基金暴露的研究记录

每个改变建议的重要事件至少记录

```text
事实及原文链接
事件发生时刻 公开发布时间 当前可用性
此前预期与本次变化 没有可靠预期数据就写未知
影响机制 收入 成本 现金流 实际利率 汇率或风险溢价
受影响的行业及公司
基金实际暴露 比重与披露时点
已观察到的价格反应及对应时段
反面证据 可替代解释
影响可能持续多久 与约一个月期限是否匹配
使本判断失效的新事实
```

同一事件可以同时产生正反影响 例如降息可能降低银行融资成本也可能压缩净息差 不机械贴单一利好或利空标签 PMI行业强势不等同该行业每家公司盈利改善

联接基金的主要暴露来自目标ETF 自身前十大直接股票之和可能很小 不据此把它归为低股票仓位 从上层基金到ETF再到指数或成份公司核查 避免重复计权

## 5 对候选完成16个角度的筛查

1. 信息真伪 来源链 时间和修订
2. 新信息相对市场预期的差异及是否已经兑现
3. 跟踪指数 持仓穿透 集中度和披露滞后
4. 经济需求 就业 通胀与信用周期
5. 利率 实际利率 融资成本和流动性
6. 政策对象 金额 执行日期及兑现路径
7. 行业供需 产品价格 库存 订单与竞争
8. 核心公司盈利质量 现金流 指引和资产负债状况
9. 估值与盈利匹配 历史区间及可比口径
10. 价格 成交 市场覆盖面 风格与资金拥挤程度
11. 海外政策 汇率 跨境限制及交易时差
12. 基金人员 流程 管理机构 费用 规模与跟踪质量
13. 申购赎回费用 持有批次 日历 确认和到账
14. 与现有组合的重复暴露 相关性及单一风险集中
15. 未来一个月已知事件日历和无法提前控制的事件风险
16. 退出依据 扣费结果 最大回撤 现金占用及基准比较

每个角度标记支持 反对 中性 不适用或待核验 不要求所有因素都齐全才给判断 但关键证据或可执行性未核实的行不得伪装成已验证买入 不将16项相加生成未经验证的获利评分

对主动基金借鉴Morningstar的人员 流程 管理机构与费用比较 对指数基金重点看跟踪质量 成本与指数构成 这些是产品选择方法 不等于一个月涨跌预测 不生成自称Morningstar官方的评级

## 6 建议动作与金额

按证据比较全池 不因用户愿亏就机械选择波动最大的基金 不因为前一轮观望就延用到新增候选

动作限定为买入 持有 卖出 观望 待核验 给出主要依据与最关键的反面因素 不以消息数量代替影响强度 不将涨跌停 股票交易机制或杠杆工具强加给场外基金任务

先提出合理的目标暴露再计算本次增减金额 不使用固定无依据的百分比自称最优仓位 若只是小额体验安排 明确其为实验预算选择而非经过验证的收益优化

买入总额不得超过已知已到账现金 不使用在途赎回款 同一基金不得同时建议新增买入与赎回 份额限制和最低金额按渠道规则核实 不确定时说明条件而不是向上凑整突破预算

卖出优先按已确认可赎回份额表达 可附参考金额 明确实际按确认净值及费用计算 部分卖出需考虑先进先出等实际批次规则 不把全部卖出后预计金额保证成确定回款

不把止损点说成可保证的最大亏损 基金未知价和到账延迟可能使实际结果偏离建议时的参考值 不强制持满7天或30天 已失效逻辑需要结合费用及时复核

## 7 发布前核查

- 日期与数据截至一致 每行产品身份 来源 日涨跌口径可核实
- 至少10只不同产品 未取到数据的行如实写待核验 不拿旧净值冒充最新
- 观察结论不自动成为买入卖出指令 0元是本次不买 不是报价或收益缺失
- 所有建议金额合计可复算 卖出不超过已确认可卖份额
- 正面依据和反面证据不矛盾 关键不确定性已传达
- 简短消息遵循四列格式 不附长篇逐步推理 不声称本技能能够盈利

研究中间证据可在任务允许的 `work/mm-money-fucker/` 留存 最终结构化建议以advice类型追加至用户配置状态目录 原文链接保留在report的url reason或notes中 不默认新建长期投资报告文档 不保存登录凭证

## 8 持续评估

按用户实际反馈更新持仓与现金 只更新已确认事实 不自动把建议单转为成交单

每次研究读取持久记录的最新事实 最终建议保存为advice 用户明确表示未执行 已执行 部分执行或不确定时保存feedback并关联advice_id 成交详情另存trade 持仓截图另存snapshot 无法对应某次建议时只记事实 不强行归因

长期复盘使用history并排除已被更正记录的有效口径 同时保留原始记录供审查 对比建议与实际执行 跟踪持仓变动 组合暴露 已实现与未实现收益 费用 回撤及持有时长 有完整外部入金出金记录时才计算相应账户收益率 充值不算收益 赎回在途不算已到账 单张持仓收益或不连续截图不足以推出完整年化收益和最大回撤 缺少区间数据时明确只能分析已观察时点

若用户要求检验AI效果 另建明确标为模拟的对照账户 比较同起始资金和区间的简单持有与现金基准 纳入实际费用 分红 现金闲置 在途时间 回撤和换手 不只报告盈利的一侧 不回填或改写旧建议

回测只允许使用当时已经公开的事件 净值和持仓 使用收盘后才知道的数据产生信号时不能假设仍按此前可下单的当日基金净值成交 不把最近一个月成功视为长期能力证明
