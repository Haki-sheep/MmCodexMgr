# 问题索引

从症状或错误词找相近条目 先做该行的区分检查 再读对应诊断 不按项目顺序浏览

ID 创建后保持稳定 不因增删重排 同一个原因和修复条件重复出现只补来源 新的条件分支按 [反馈机制](feedback.md) 增加变体
