## 本轮有效做法 不冒充已发生的错误

这些做法可按问题复用 本轮没有证据表明执行者曾犯下相反错误

- 当前 DLL 与旧反编译的枚举不同 当前 0x104 为 BulletRecoilFactor 0x106 为 BlastDamageMul 不能统一平移映射 另一 AIData getter 的 0x250 也不借用属性表命名
- Infected 死亡条件在首次 F20 返回真后再次查询 F20 保留两次读取和调用顺序 通过 true/false 序列验证 不把重复查询缓存掉
- 光照函数跨 unwind 分片 完整提取为 245 字节 死亡原字节 mock 执行与光照静态恢复真值检查分开记录
- 未知深层查询保留明确接口和来源 不命名成未经证明的血量 UV 或视线含义 不用默认 false 取得表面完整的 AI
- 多个数值向量属于一项检查时保持组计数和向量计数分开 独立复验既有结果不重复累计成新增功能

## 执行者的最小交付信息

按实际任务裁剪 不要求每个小改动新建报告或独立评审

- 改动文件和提供给集成人的入口 已依赖的来源版本及哈希
- 支持的输入与实际消费范围 未应用内容 未知端口和明确拒绝项
- 实际运行的命令 退出结果 首错以及验证层级 使用 mock 或 stub 时标明替代了哪些部分
- 与同一基线有关的已有证据 可复用项和新组合还需要验证的关系

最有效的提速是先暴露会改变接口或结论的反例 减少同质样本 重复读取和交付后补协议 不承诺未测量的速度倍数
