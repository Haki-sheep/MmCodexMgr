# 债务治理前后评分

## 分数含义

维护质量分 0 至 100 越高表示所查范围的已观察维护负担越低
这是固定口径的工程量表 不是经统计校准的故障概率 全工程质量认证或真实工时估计
采用等权维度避免临场调整权重 评分只支持同范围前后比较 治理优先级仍使用主文件的三个档位

## 固定维度

| 维度 | 关注的额外维护成本 |
| --- | --- |
| 修改传播与职责边界 | 一次业务修改需要跨越多少独立职责边界 是否被迫修改无关模块 |
| 规则与状态单一来源 | 同一规则或权威状态是否需要多处同步 人工核对或反复适配 |
| 生命周期与资源归属 | 生命周期或释放责任是否需要调用方重复补偿 并产生已有维护或运行代价 |
| 契约与演进兼容 | API 数据 资源或序列化演进是否需要额外迁移 手工修引用或兼容绕行 |
| 变更验证与定位成本 | 修改后能否通过既有可重复流程验证 是否反复依赖人工排查或无法定位回归 |

只判断与当前范围有关的维度 不因缺少某种框架 接口或自动化测试直接扣分
确实不适用的维度标记 N/A 并给范围证据 未检查或证据不足不能标记 N/A
纯无状态模块没有资源 事件或异步任务时 生命周期维度可为 N/A 已有公开契约但窗口内没有变更时 契约维度仍适用 根据覆盖证据判档
同一根因选最直接的一项维度计分 只有证据证明另有独立成本时才影响其他维度 并解释为何不是重复扣分
去重只排除同一成本的重复扣分 不能据此把其他维度自动判为 0 其他维度仍需独立覆盖证据

## 负担档位与依据

每个适用维度使用同一组 0 至 4 档位 不允许自由填写小数档位

| 负担档位 | 证据要求 | 该维度质量比例 |
| --- | --- | --- |
| 0 | 所查入口及代表性修改路径证据充分 未观察到该维度的额外负担 | 100% |
| 1 | 有局部额外步骤 成本限制在同一职责边界内 无需同步独立维护入口 | 75% |
| 2 | 同一修改需同步多个独立入口 或需要明确的手工核对与适配 当前流程仍可完成 | 50% |
| 3 | 已有多次返工 回滚 故障或重复测量记录 且结构根因已确认 当前仍可通过已知补偿完成工作 | 25% |
| 4 | 已有证据表明当前任务或必要验证被该根因阻断 暂无已验证的可接受处理办法 | 0% |

同一维度取证据支持的最高负担档位 不按债项数 文件数 行数或 API 命中次数累加扣分
另报债项数量与成本 防止相同分数掩盖多个独立问题
0 档也需要正向覆盖证据 无发现但未检查不等于满分
档位无法确定时保留上下界 如明确至少存在局部负担但未知传播范围则不能擅定精确档位
没有可用证据时负担区间为 [0, 4] 保留在分母中 不把未知当零成本或直接删掉
只有与该维度及当前快照匹配 且覆盖相关关键路径的证据才能排除某一档位 局部债项没有阻塞不代表整个维度可以排除 4 档

## 计算

设适用维度数为 N 各维度负担档位为 L

`质量分 = 100 × Σ(4 - L) / (4 × N)`

全部五维适用时 每个维度满分 20 每升一档扣 5 分
维度为负担区间时 使用各维度上界计算分数下界 使用下界计算分数上界
分数下界向下取整 上界向上取整 保留区间 不把中点作为实际得分
全部档位确定时分数四舍五入到整数 全部维度不适用时写不适用 不输出 100
使用可执行计算核对结果 不在心算结果上构造虚假的精度

## 覆盖与置信度

评分表每行给 维度 负担档位或区间 债项 ID 代码或记录引用 具体评分理由
说明代表性修改路径如何选取 关键入口是否遗漏 有无反例 不为了提高分数挑选容易的路径
覆盖分别报告 确定档位数/N 部分证据但未定档数/N 完全未知数/N 以及 N/A 项数 三类适用维度合计为 N
仅填 [0, 4] 属于完全未知 不能计入已覆盖 同时列出已查入口和未查入口 不把覆盖率当成正确概率

- 高 所有适用维度有直接且与当前快照匹配的证据 关键入口及代表性修改路径覆盖 已知反例已核对 涉及运行代价的项有可比记录
- 中 存在可解释的代理指标或有限样本 但已明确适用边界与未证实部分 分数可为区间
- 低 关键入口未查 历史或必要运行数据缺失导致主要成本无法判断 或范围与快照不清

置信度不转换成伪精确百分比 引用次数多不自动升级置信度
信息缺口必须解释它会使哪项档位不确定 不能只附一句缺少更多测试

## 前后比较与输出

最后输出

| 阶段 | 快照与范围 | 维护质量分 | 覆盖与置信度 | 评分理由 |
| --- | --- | --- | --- | --- |
| 债务治理前 | 修改前实际快照与所查入口 | 按证据计算的分数或区间 | 维度覆盖 关键缺口及高/中/低 | 主要成本与债项引用 |
| 收敛后 | 修改后实际快照与复查记录 | 按相同口径复算 或未复评 | 同口径证据与剩余缺口 | 哪些额外步骤已消除 哪些仍存在 |

未实施修复 未保存可信基线 或未完成相应复查时如实标记 不回填一个想象的治理前或收敛后分数
只做盘点时 当前快照可作为以后治理的前评分 收敛后写未复评
前后范围 适用维度 档位规则与采样条件应一致 发生变化则用同一新口径重评两端 否则不算提升
每项升分说明原负担档位 新档位 实际变化和验证引用 文件减少或函数拆分本身不能证明成本降低
补充证据或纠正旧判断导致的分数变化单列为基线修订 不能计为偿还收益
区间比较时提升范围为 [后分下界 - 前分上界, 后分上界 - 前分下界] 区间包含零时不宣称已证实提升
目标分和预期收益如有需要另列为预测 不能放进收敛后实测栏
100 分只表示本次范围和证据下该量表未见额外负担 不等于没有缺陷或可以交付
