# Unity 债务证据

仅在已定位的债务涉及 Unity 契约时读取 不逐项扫描整个工程
项目规则决定生成路径 UI 框架 初始化入口与数据工具 不在通用 Skill 固定这些约定

## 生命周期与资源

区分 MonoBehaviour 实例生命周期 OnEnable 与 OnDisable 激活周期 对象池租用周期和业务数据绑定周期
依据实际拥有者与调用链判断事件 Tween 协程 异步结果和加载句柄的释放责任
利用已有重开 复用或切场景故障记录定位重复维护的根因 不把一次性初始化规则套到重复绑定
已有 Addressables 或其他资源加载代码需明确归属时 按当前项目版本和用法查证释放契约 不臆测 API 行为

## 资产与程序集

重命名或删除涉及序列化时 核实 .meta GUID Prefab 场景 覆盖项与动画事件等实际引用
代码引用搜索没有结果不足以证明序列化入口无人使用 二进制资产或缺失 Editor 时说明检查盲区
asmdef 依赖根据实际类型所属程序集判断 命名空间和 using 不等于程序集依赖
Luban UI 生成器等以项目识别出的权威输入为准 修改生成产物造成的反复覆盖可作为债务证据
不通过改 PackageCache 或手工改生成物消除表面问题 不为审计自动运行生成器

## 构建与性能证据

只在已有债务线索涉及平台差异时关注 Editor 条件编译 IL2CPP AOT 裁剪和资源打包
Unity 编辑器编译或生成的 .csproj 构建不能证明目标平台运行行为
消费已有 Profiler Memory Profiler 或设备记录时记录版本 平台 设备 场景 数据规模与采样条件
静态热点只能标记风险 不把某个 API 调用 每帧分配或复杂度直接换算为卡顿与治理评分
用户授权性能治理后的复测须使用可比条件 未复测就不宣称性能债务已经收敛
