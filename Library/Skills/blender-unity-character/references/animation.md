# 已有骨架角色的动画制作与修改

先核对骨架 蒙皮 Action 或 NLA FPS 与帧区间 优先复用已有动作 只制作或修改本次要求的动作。

1. 在源文件副本中制作 为指定骨骼设置位移 旋转或缩放并插入关键帧 生成或更新对应 Action。
2. 根据实际骨骼静止姿态和局部轴制作 骨轴与世界轴不一致时先转换到骨骼局部空间 不套用其他角色的骨骼名或旋转参数。
3. 根据动作要求安排预备 主动作 恢复和次级运动 涉及待机时检查首尾循环 攻击与受击检查恢复 死亡检查末帧保持。
4. 保留未要求修改的 Action 骨骼名称和层级 沿用实际 FPS 动作长度及稳定导出设置 不运行会删除已有 Action 的重建脚本。
5. 明确选择 Action 或 NLA 导出 避免遗漏与重复 起止帧有关键帧 必要时烘焙 骨架与蒙皮一起导出。
6. 新建导出配置可从 `axis_forward='-Z'` `axis_up='Y'` `add_leaf_bones=False` 开始 以 Unity 实测确认单位 尺寸和朝向。

## 验证

验证本次涉及的动画曲线 实际采样变形 循环或末态 Animator 参数和过渡 Prefab 与外部引用 不为验收新增未要求的动作。
