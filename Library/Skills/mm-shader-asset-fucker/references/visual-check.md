# 视觉对照

先说明采集范围是 GameView 实录 还是独立场景的相机渲染 不把离屏预览称为用户当前窗口录像

比较原编译 Shader 与还原源码时保持相机 姿态 光照 材质参数 时间及关键字条件一致 只在克隆材质或隔离预览实例上替换 不给其中一侧额外加灯

Timeline 的资产 duration 可能为零而实际存在 clips 仅在预览副本上依据 clip end 设置有效长度 不修改原 Timeline

手动 Evaluate 后的相机约束未必已更新 先核对目标 Weight Up 配置与旋转偏移 超出已验证配置就报告限制 不套固定朝向公式

动态速度线 粒子和时间采样可能使同一原版材质连续 Camera.Render 的结果不同 先做原版对原版重复渲染控制 再解释差异 固定时间或暂停粒子没有消除波动时如实说明

发现稳定差异时逐个 Shader 替换归因 结合原字节码 反汇编和 Unity 读取到的材质参数定位 修复生成器后重新导出 禁止用局部贴图遮挡或给两侧不同参数来伪造一致

报告预览覆盖的角色 材质 关键字与采样时间 未进入画面的资源不能算视觉验证通过 编译结果与像素等价分别记录
