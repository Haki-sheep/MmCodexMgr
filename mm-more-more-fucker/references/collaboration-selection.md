# 协作方式选择

用于实际任务的分工决策 预算与授权以 [SKILL.md](../SKILL.md) 和当前工程规则为准 本文不授予创建会话 worktree 或扩大任务范围的权限

## 任务适配

| 代号 | 方式 | 适用任务 | 典型交付 |
| --- | --- | --- | --- |
| A | 原生子代理 | 当前任务内可独立推进的调查 测试 分析或局部实现 | 指定模块的问题位置 验证证据或范围明确的改动 |
| B | 同实例会话联调 | 同一 Codex 实例内需要多轮持续推进并分别保留历史的模块协作 | 客户端与服务端联调 模块间接口约定及集成结果 |
| C | 跨实例或跨工具 Agent 协作 | 需要不同实例配置 工具或执行环境的工作 | Codex 实现与 Cursor 审查 或其他实例中的独立验证 |

三种方式可以组合 只为有清晰输入 输出与验收条件的独立单元增加协作 不把文件数 代码量或预计耗时单独作为分派依据

短期子任务优先考虑 A 需要长期独立会话历史时考虑 B 确实依赖其他实例或工具环境时考虑 C 目标或依赖仍频繁变化时先由当前 Agent 澄清接口和共享资源归属

B 与 C 都是独立执行会话 默认各可用 3 个原生 Subagent 不要求凑满且每个都须有实际工作 A 原生子代理只能作为叶子执行 不得继续创建 Subagent 或转派下级 可以接收原主会话的后续任务

## 上下文与文件

| 内容 | A 原生子代理 | B 同实例会话 | C 跨实例或跨工具 Agent |
| --- | --- | --- | --- |
| 上下文窗口 | 各自独立 | 各自独立 | 各自独立 受各自模型与配置约束 |
| 创建时的历史 | 是否继承及继承范围取决于宿主工具 | 普通新会话不自动继承 显式 Fork 可继承当时历史 | 不因建立协作关系而继承对方历史 复用时保留自身历史 |
| 后续同步 | 通过消息与结果回传 | 通过任务派发 补充消息或主动读取 | 通过管理器 消息或交接文件 |
| 文件读取与工具日志 | 默认留在执行线程 | 默认留在执行会话 | 默认留在各自会话或环境 |
| Skill | 依宿主与代理配置发现并加载 | 可发现共同配置的技能 各自按需读取正文 | 依各自安装与配置 不随任务消息自动复制正文 |
| 磁盘文件 | 当前宿主可能共享同一工作区 | 同目录共享修改 不同 worktree 分别维护文件 | 依实际目录与存储决定 跨设备需要同步 |

文件共享不等于上下文共享 接收方需要读取文件或收到必要内容才能获得相关事实 文件修改后也需要重新读取才能获知新状态

## 交接与 Token

交接提供目的 可写范围 必要背景 已确认的接口与约束 验收条件及已有验证证据 使用具体文件路径和符号定位信息 不复制整段聊天或大段无关工具日志

宿主支持控制历史继承时 依据子任务需要选择继承范围 不遗漏会改变结果的业务约束 下级回传实际改动 关键证据 未验证项与未解决问题 由主 Agent 验证并整合

| 指标与前提 | 比较 |
| --- | --- |
| 各代理上下文窗口独立性 | A=B=C |
| 同模型且总输入与输出 Token 相同的消耗 | A=B=C |
| 初始背景 Token A 继承长历史 B/C 新建且只接收短摘要 | A>B≈C |
| 组织与交接复杂度的常见倾向 | C>B>A |
| 实际任务总 Token 消耗 | 无固定排序 |

消耗取决于继承历史 重复读取 工具输出 参与代理数量与协作轮数 模型与服务的计价还会影响费用 不按会话所在实例推断成本 排序只用于比较已注明的前提 不作为性能保证
